# obix-compiler-styles

> Previous name: `@obinexusltd/obix-compiler-styles` — OBIX packages are named without an npm scope since decision D-102 (2026-09-29); the package, its version and its exports are unchanged.

**Scoped CSS transformation for OBIX.**

```bash
npm install obix-compiler-styles
```

## Purpose

| Export | Role |
|---|---|
| `scopeCss(css, token)` | rewrite selectors so rules only match inside the component scope |
| `scopeComponentCss(name, css, path?)` | token + scope in one call |
| `createScopeToken` | re-exported from `obix-core-spec` — the **one** token function |
| `SCOPE_ATTR` | `"data-obix-scope"` |

The rightmost compound selector of every rule gets `[data-obix-scope="<token>"]`.
`@media` / `@supports` / `@container` blocks are recursed into; `@keyframes` and
`@font-face` are left untouched.

## Problem 10 — no token drift

`obix-compiler-styles`, the compiler, the native emitter and the SSR emitter **all** call
`obix-core-spec.createScopeToken`. This package never re-implements it.

## Dependency role

Depends only on `obix-core-spec`. Consumed by `obix-compiler-emit`.

## Level 0 status

✅ Class / element / id / descendant / combinator selectors, media queries.
Deferred: SCSS, `:deep()` escapes, CSS nesting.

`obix-compiler-styles` is part of the **OBIX compiler** (build-time tooling): it never runs in an application's browser graph.
